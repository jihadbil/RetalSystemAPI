# نظام تصميم Emerald Pro لسطح المكتب

مرجع التنفيذ: WPF / .NET 10. تحديث 7 سبتمبر 2026.

## القواعد الأساسية

- اتجاه عربي RTL؛ الباركود والمبالغ المكتوبة تستخدم LTR عند الحاجة لمنع اضطراب الأرقام.
- الموارد في Resources/Themes تحدد الأسطح والنصوص والحالات. أي لون يعتمد على الثيم يستدعى بـ DynamicResource.
- الأزرار الأساسية تستخدم PrimaryButtonStyle وPrimaryOnBrush. الزمردي للفعل الرئيسي، والحذف إجراء ثانوي بلون دلالي.
- الخط AppFontFamily: Cairo مع بدائل Windows. العناوين 22، العناوين الفرعية 17، المتن 13–14، والملاحظات 12. الإجمالي في نقطة البيع 30.
- الحواف 8–10 للأجزاء التفاعلية و10–12 للبطاقات. لا يتطلب كل عنصر بطاقة مستقلة أو ظلًا.
- تباعد الشاشة 16–20، وتباعد الأقسام 12–16، وحقول المهام الأساسية بارتفاع 36–42.
- كل عنصر قابل للاستخدام بلوحة المفاتيح يظهر تركيزًا واضحًا. أزرار الأيقونات لها أسماء وصول أو نصوص واضحة.

## القوالب المشتركة

| العنصر | موضعه | السلوك |
|---|---|---|
| الأزرار والتركيز | ButtonStyles + WorkspaceStyles | أساسي، ثانوي، نصي، وخطر؛ مؤشر تركيز ظاهر |
| الإدخال | TextBoxStyles | مسافة داخلية واحدة؛ عرض القيمة بلا قص؛ دعم أخطاء الربط والتحقق |
| القوائم المنسدلة | ComboBoxStyles | أسماء السجلات، بحث الكتابة عند تفعيله، وقائمة متوافقة مع الثيم |
| الجداول | DataGridStyles | ارتفاع صف مناسب، أعمدة قابلة للتمرير، ومحاكاة افتراضية للصفوف والأعمدة |
| الصفحات | PaginationControl | السابق/التالي وحجم الصفحة دون تداخل؛ تعطيل أثناء التحميل |
| النماذج | WorkspaceWindowBehavior | التكيف مع مساحة العمل، حفظ متاح بالتمرير، تأكيد مغادرة المدخلات المعدلة |
| الرسائل | LoadingOverlay + EmptyStateControl + ToastService | فصل التحميل والفشل والخلو والنجاح |

## نقطة البيع

قشرة قابلة للطي، باركود في الأعلى، سلة واسعة، ملخص مالي ثابت، ودفع واضح. عند عرض أقل من 780 وحدة ينتقل الدفع أسفل السلة ويصبح الوصول إليه عبر التمرير؛ لا تُصغّر الحقول لإجبارها على البقاء جنبًا إلى جنب.

| المفتاح | الوظيفة |
|---|---|
| F1 | حقل الباركود |
| Enter في الباركود | إضافة الصنف إلى طابور المسح |
| F2 | البحث عن صنف |
| F3 | إضافة عميل |
| F4 | إظهار الأصناف السريعة |
| F5 | تعليق الطلب |
| F6 | استعادة الطلب المحدد إذا كانت السلة فارغة |
| F8 | وضع المبلغ المستلم مساويًا للإجمالي |
| F9 | الدفع بالبطاقة |
| F10 | حفظ البيع بعد التحقق |
| F11 | إظهار/إخفاء قائمة التنقل |
| Escape | السلوك المعتاد للعنصر النشط؛ لا يمسح السلة |

المبلغ المستلم لا يتغير تلقائيًا مع الإجمالي. الفرع والمخزن والعميل والبنود والخصم والضريبة والدفع والملاحظات تحفظ في المسودة. الحفظ محلي على الجهاز لكل مستخدم ومنشأة، وليس مزامنة بين الأجهزة. لا تعرض أيقونة طباعة على إجراء يحفظ فقط.

## القوائم والنماذج

قائمة المنتجات هي المرجع: بحث مسمى، إجراء إضافة رئيسي، أدوات Excel ثانوية، وصورة تحافظ على نسبها. العملاء والموردون يستخدمان مكون الصفحات نفسه وبحثًا مؤجلًا قصيرًا. تخبأ الأرصدة الافتتاحية للمنتج داخل قسم اختياري؛ التبويبات مخصصة للبيانات الأساسية والوحدات والباركودات والصور.

لا يغلق النموذج أثناء عملية تحميل/حفظ نشطة. الإغلاق بعد نجاح الحفظ يعيد DialogResult=true لتمييزه عن الإلغاء. أخطاء الأرقام لا تسمح بحفظ قيمة قديمة مخفية خلف إدخال غير صالح.

## التحقق

تشغيل الاختبارات المستقلة:

```powershell
dotnet run --project tests/RetalSystemAPI.Desktop.UxChecks -- --render
```

تستخدم الاختبارات خدمات وهمية، وتولّد معاينات من ملفات XAML الفعلية في artifacts/desktop-ux. لا تسجل الدخول ولا تتصل بقاعدة بيانات المتجر. يلزم أيضًا اختبار قبول على أجهزة الكاشير الفعلية، خصوصًا المسح والطباعة وتغيير تكبير Windows.
