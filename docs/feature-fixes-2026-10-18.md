## التحقق

- الاختبارات الأصلية للخادم: 146 حالة، مع تشغيل SQL Server.
- أُضيفت اختبارات انحدار للمخزون والفروع والمرتجعات والهواتف وكشوف الحساب والاستيراد وعزل الملفات، واختبارات صلاحيات نقطة البيع والتحصيل المصرفي.
- اختبارات الويب تغطي عقود الهواتف والمنشأة، وحفظ بيانات العميل، وحسابات تحصيل نقطة البيع، وإجراءات الترحيل، وفتح الميزات الفرعية، وباركودات وقيم بنود المرتجعات.
- تحقق الواجهة يشمل TypeScript وVite وESLint وVitest.

## حدود التحقق والتوافق

- استُبعد كود سطح المكتب واختباراته، ولم يُبنَ ملف الحل الذي يتضمنهما.
- لا توجد تغييرات على مخطط قاعدة البيانات أو ملفات ترحيل جديدة. لم تُنفذ معالجة تلقائية لبيانات قديمة تأثرت بالأخطاء السابقة.
- لم تُنفذ جلسة متصفح شاملة؛ تغطية الويب آلية على مستوى العقود والمنطق والبناء والفحص، مع مراجعة تدفق المكونات.
- إنشاء مبيعات الكاشير ينتقل إلى `/api/pos-sales`؛ العملاء الآخرون الذين يستعملون دور Cashier ومسار إنشاء الفواتير العام يحتاجون إلى اعتماد المسار المخصص.
- الاستلام وإكمال التحويل ينفذان أثرهما عبر خدمات الترحيل الموجودة. تتطلب بيانات المورد والمستودع صلاحية التعديل، ويتطلب الترحيل صلاحية الاعتماد، وتبقى صلاحيات القوائم المساعدة مطلوبة بحسب الدور.
